# Mực & Khung

Website storefront Next.js cho một nhà xuất bản truyện tranh độc lập.

## Chạy local

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Kiểm tra nhanh

- Lọc bộ sưu tập theo thể loại.
- Thêm truyện, tăng/giảm số lượng và xoá trong giỏ hàng.
- Kiểm tra CTA đặt hàng hiển thị thông báo demo.
- Gửi email hợp lệ ở phần newsletter.
- Chạy `npm run build` để kiểm tra production build.
